WHAT IS API
- API allows communication between two systems

Flow:
User → Python → API → Server → JSON → Python Output


HTTP METHODS

GET:
- Used to receive data

POST:
- Used to send data


JSON
- Lightweight data format

Example:
{
    "name": "Shahzad"
}

Python:

HEADERS
- Extra information sent with request

Examples:
- User-Agent
- Accept
- Authorization


USER-AGENT
- Identifies client making request
Example:
Python requests / Browser


ACCEPT HEADER
- Tells server response format needed
Example:

AUTHENTICATION (AUTH)
- Verifies user identity

Flow:
User → Credentials → Server → Database → Verified

Authentication = Who you are
Authorization = What you can do


JSON PARSING

🔹 WHAT IS FASTAPI?

FastAPI is a Python framework used to build APIs (backend services).

It helps to:

Handle HTTP requests (GET, POST)
Validate input data
Build backend systems
Connect AI models with APIs
🔹 HTTP METHODS
GET → Fetch data
/user/1
POST → Send data
{
  "name": "Ali",
  "age": 22
}
🔹 PATH PARAMETERS

Dynamic URL values.

@app.get("/user/{user_id}")
def get_user(user_id: int):
    return {"user_id": user_id}

✔ Used for dynamic routes
✔ Example: /user/10

🔹 QUERY PARAMETERS

Used for filtering data.

@app.get("/search")
def search(name: str = None, age: int = None):
    return {"name": name, "age": age}

Example:

/search?name=Ali&age=22

✔ Used for optional filters

🔹 REQUEST BODY (IMPORTANT)

Used to send JSON data in POST requests.

from pydantic import BaseModel

    name: str
    age: int

    return user

✔ Used in POST APIs
✔ FastAPI validates automatically

🔹 FILE UPLOAD (PDF)
from fastapi import File, UploadFile
from pypdf import PdfReader

@app.post("/upload-pdf")
async def upload_pdf(file: UploadFile = File(...)):
    reader = PdfReader(file.file)
    text = ""

    for page in reader.pages:
        text += page.extract_text()

    return {"text": text[:1000]}

✔ Reads PDF files
✔ Extracts text

🔹 PDF CHATBOT (RAG SYSTEM)

Flow:

PDF → Extract Text → Store → Question → AI Answer
🔹 PDF CHATBOT CODE
pdf_text_storage = ""

@app.post("/upload-pdf")
async def upload_pdf(file: UploadFile = File(...)):
    global pdf_text_storage

    reader = PdfReader(file.file)
    text = ""

    for page in reader.pages:
        if page.extract_text():
            text += page.extract_text()

    pdf_text_storage = text

    return {"message": "PDF uploaded", "length": len(text)}
class PDFQuestion(BaseModel):
    question: str


@app.post("/ask-pdf")
def ask_pdf(data: PDFQuestion):

    response = client.chat.completions.create(
        model="llama-3.1-8b-instant",
        messages=[
            {
                "role": "system",
                "content": "Answer ONLY from PDF content"
            },
            {
                "role": "user",
                "content": pdf_text_storage + "\n\nQuestion: " + data.question
            }
        ]
    )

    return {"answer": response.choices[0].message.content}
